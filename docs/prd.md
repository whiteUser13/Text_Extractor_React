# 报告文件智能化审核应用系统需求文档

## 1. 系统概述

### 1.1 系统名称
报告文件智能化审核应用系统

### 1.2 系统描述
开发一个报告文件智能化审核应用系统，主要功能包括文件上传下载、文件解压缩、格式转换、多模态内容解析、自定义规则提取和判别、成果表格输出等。用于应用于地块违规建设情况报告审核、土壤与水污染报告审核、地块报告中信息提取等业务场景以及未来的各种报告审核业务。

### 1.3 总体目标
构建一个自动化、产品化、定型化的报告审核平台，实现多格式多模态报告的"转换-解压-解析-检索-提取-判别-输出"全流程处理，快速响应新的报告审核需求。

## 2. 核心技术架构

### 2.1 技术选型
- 多格式文件处理：Apache POI、PDFBox等
- 文件解压缩：支持zip、rar等压缩格式处理
- OCR技术：Tesseract
- NLP技术：spaCy
- 数据库：存储文件元数据、解析结果和用户规则
- 前端：可视化组件支持规则配置界面
- 实时数据更新机制：支持错误统计和进度展示

### 2.2 核心处理流程
1. **转换**：将报告文件转换为可解析的格式
2. **解压**：对压缩文件进行解压缩处理
3. **解析**：把报告内容解析为包含原有结构、页码、逻辑关系的可检索内容
4. **检索**：采用自定义检索规则进行内容检索
5. **提取**：对检索内容进行整理提取为结构化数据
6. **判别**：基于自定义判别规则输出结构化判别结果
7. **输出**：生成成果表格并支持导出

## 3. 功能模块

### 3.1 首页管理模块
- 系统概览信息展示
- 处理报告数量统计
- 过程环节错误信息统计
- 具体处理进度展示
- 报告处理阶段状态监控
- 前端管理界面实时数据更新

### 3.2 报告文件批量上传与下载模块
- 多种常见格式文件上传下载功能（doc、docx、word、pdf、压缩包、扫描件pdf等）
- 后台数据库台账信息管理
- 文件信息监测记录（编号、文件名、格式、大小等）
- 上传下载统计功能
- 系统管理界面信息展示
- **文件解析结果预览功能**：文件上传并解析处理后，提供预览界面展示解析后的结果内容

### 3.3 文件解压缩处理模块
- 自动识别压缩文件格式
- 一键解压缩功能按钮
- 支持多种压缩格式（zip、rar等）
- **解压缩日志板块**：
  - 显示文件解压缩成功或失败状态
  - 文件大小检测：对于1kb、2kb等过小文件显示"文件有问题，请核查"提示
  - 解压缩过程实时日志记录
- 解压缩结果统计与监控

### 3.4 文件格式批量转换模块
- 根据文件类型自动选择合适转换工具
- 支持Apache POI、PDFBox等转换工具
- 将报告文件转换为便于信息提取的格式（word、pdf、markdown等）
- 转换过程状态监控

### 3.5 报告多模态内容批量解析模块
- 利用OCR技术（Tesseract）进行图像文字识别
- 利用NLP技术（spaCy）进行文本处理
- 全文解析功能，包括：
  - 文章目录解析
  - 页码识别
  - 文本内容提取
  - 表格识别与解析
  - 图片识别与处理
  - 逻辑关系保持
- 解析错误统计与系统界面显示

### 3.6 报告指定自定义内容批量检索提取模块
- 用户检索提取规则设置界面
- 支持多种检索条件：
  - 具体内容关键词
  - 特定章节定位
  - 页码范围指定
- 检索结果结构化数据表生成
- 可导出功能支持

### 3.7 报告指定内容自定义规则判别模块
- 用户审核判别规则设计界面
- 自定义审核规则设置功能
- 多种判别类型支持：
  - 合规性判别
  - 等级分类判别
  - 含义解释判别
- 判别结果结构化数据表制作
- 可导出结构化数据表功能

### 3.8 成果表格输出模块
- **文档特定内容表格化输出**：将每个文档的特定内容整理输出为表格形式
- 支持多种表格格式导出（Excel、CSV等）
- 表格内容可自定义配置
- 批量文档成果表格生成
- 表格模板管理功能
- 成果表格预览与编辑功能

## 4. 支持的文件格式

- 页眉页脚处理
