# 报告文件智能化审核应用系统

一个现代化的报告文件智能化审核应用系统，支持多格式文件上传、解析和预览功能。

## 功能特性

### 📁 文件上传与管理
- **多格式支持**: PDF、Word文档(doc/docx)、图片、压缩包等
- **无文件大小限制**: 支持上传任意大小的文件
- **多种上传方式**: 
  - 点击"选择文件"按钮
  - 点击整个上传区域
  - 拖拽文件到上传区域
- **实时状态监控**: 上传中 → 处理中 → 完成
- **批量处理**: 支持同时上传多个文件

### 🔍 智能解析与预览 (v4新增)
- **多模态内容解析**: 
  - 文本内容提取
  - 表格识别与解析
  - 图片识别与处理
  - 文档结构分析
- **预览功能**: 
  - 文档概览信息
  - 完整文本内容展示
  - 表格数据可视化
  - 图片内容预览
  - 文档结构树状图
- **智能分类**: 根据文件类型生成不同的解析结果

### 🎨 用户体验
- **现代化界面**: 基于shadcn/ui组件库的美观界面
- **响应式设计**: 适配桌面和移动设备
- **实时反馈**: Toast通知和进度条
- **状态指示**: 清晰的文件处理状态显示

## 技术架构

- **前端框架**: React 18 + TypeScript
- **UI组件**: shadcn/ui + Tailwind CSS
- **状态管理**: React Hooks
- **文件处理**: 模拟OCR和NLP技术
- **构建工具**: Vite

## 使用说明

### 文件上传
1. 进入"文件上传"页面
2. 选择或拖拽文件到上传区域
3. 系统自动开始处理文件
4. 等待处理完成

### 预览解析结果
1. 文件处理完成后，点击文件列表中的"👁️"预览按钮
2. 在预览对话框中查看：
   - **概览**: 文档基本信息和内容统计
   - **文本内容**: 提取的完整文本
   - **表格**: 识别出的表格数据
   - **图片**: 检测到的图片信息

### 支持的文件格式
- **PDF文件**: .pdf
- **Word文档**: .doc, .docx
- **图片文件**: .jpg, .jpeg, .png, .gif, .bmp, .webp
- **压缩文件**: .zip, .rar, .7z
- **其他格式**: .txt, .rtf等

## 开发说明

### 项目结构
```
src/
├── components/          # 组件目录
│   ├── ui/             # shadcn/ui组件
│   ├── FilePreview.tsx # 文件预览组件
│   └── common/         # 通用组件
├── pages/              # 页面组件
│   └── FileUpload.tsx  # 文件上传页面
├── types/              # 类型定义
├── utils/              # 工具函数
└── services/           # 服务层
```

### 核心组件

#### FilePreview 组件
- 文件解析结果预览对话框
- 支持多标签页展示不同类型的内容
- 响应式设计，适配不同屏幕尺寸

#### FileUpload 组件  
- 文件上传主页面
- 集成了上传、处理、预览等完整功能
- 支持批量文件处理

### 数据流程
1. 文件上传 → 2. 格式验证 → 3. 模拟处理 → 4. 生成解析结果 → 5. 预览展示
