# 报告文件智能化审核应用系统

一个现代化的报告文件智能化审核应用系统，支持多格式文件上传、解压缩处理、解析和预览功能，以及成果表格输出。

## 功能特性

### 📁 文件上传与管理

- **多格式支持**: PDF、Word 文档(doc/docx)、图片、压缩包等
- **无文件大小限制**: 支持上传任意大小的文件
- **多种上传方式**:
  - 点击"选择文件"按钮
  - 点击整个上传区域
  - 拖拽文件到上传区域
- **实时状态监控**: 上传中 → 处理中 → 完成
- **批量处理**: 支持同时上传多个文件

### 🗜️ 解压缩处理

- **自动识别压缩格式**: 支持 zip、rar 等多种压缩格式
- **文件选择功能**:
  - 每个文件前都有复选框，支持单独选择
  - 全选/取消全选控制，支持批量操作
  - 选中文件高亮显示，提供清晰的视觉反馈
  - 实时显示选择统计信息（已选择 X / Y）
- **开始解压按钮**:
  - 只处理用户选中的文件
  - 按钮显示选中文件数量
  - 未选择文件时智能提示
- **智能文件检测**:
  - 自动检测文件大小，对 1kb、2kb 等过小文件显示"文件有问题，请核查"
  - 实时显示解压缩成功或失败状态
- **详细日志记录**:
  - 显示每个文件的处理状态和时间
  - 提供处理进度条和统计信息
  - 支持成功、失败、警告等多种状态显示

### 🔍 智能解析与预览

- **多模态内容解析**:
  - 文本内容提取
  - 表格识别与解析
  - 图片识别与处理
  - 文档结构分析
- **预览功能**:
  - 文档概览信息
  - 完整文本内容展示
  - 表格数据可视化
  - 图片内容预览
  - 文档结构树状图
- **智能分类**: 根据文件类型生成不同的解析结果

### 📊 成果表格输出

- **自定义表格模板**:
  - 预置多种专业模板（地块违规建设、土壤污染检测等）
  - 支持创建自定义模板
  - 灵活的字段类型配置（文本、数字、日期、布尔）
- **智能内容提取**:
  - 根据模板自动提取文档特定内容
  - 生成结构化数据表格
  - 支持批量文档处理
- **多格式导出**:
  - 支持 Excel、CSV 格式导出
  - 表格预览和编辑功能
  - 批量成果表格生成

### 🎨 用户体验

- **现代化界面**: 基于 shadcn/ui 组件库的美观界面
- **响应式设计**: 适配桌面和移动设备
- **实时反馈**: Toast 通知和进度条
- **状态指示**: 清晰的文件处理状态显示

## 技术架构

- **前端框架**: React 18 + TypeScript
- **UI 组件**: shadcn/ui + Tailwind CSS
- **状态管理**: React Hooks
- **文件处理**: 模拟 OCR 和 NLP 技术
- **构建工具**: Vite

## 使用说明

### 完整处理流程

1. **文件上传**: 上传各种格式的文件
2. **解压缩处理**: 对压缩文件进行解压缩，查看处理日志
3. **内容提取**: 提取文档中的关键信息
4. **智能判别**: 基于规则进行内容判别
5. **成果表格输出**: 生成结构化表格并导出

### 解压缩处理

1. 进入"解压缩处理"页面
2. 查看待处理的文件列表
3. 选择要解压缩的文件：
   - 使用复选框单独选择文件
   - 或点击"全选"按钮选择所有文件
4. 点击"开始解压缩"按钮
5. 实时查看处理日志和统计信息

### 成果表格输出

1. 进入"成果表格输出"页面
2. 选择或创建表格模板
3. 点击"生成成果表格"
4. 预览生成的表格数据
5. 导出为 Excel 或 CSV 格式

### 支持的文件格式

- **PDF 文件**: .pdf
- **Word 文档**: .doc, .docx
- **图片文件**: .jpg, .jpeg, .png, .gif, .bmp, .webp
- **压缩文件**: .zip, .rar, .7z
- **其他格式**: .txt, .rtf 等

## 开发说明

### 项目结构

```
src/
├── components/          # 组件目录
│   ├── ui/             # shadcn/ui组件
│   ├── FilePreview.tsx # 文件预览组件
│   └── common/         # 通用组件
├── pages/              # 页面组件
│   ├── Dashboard.tsx   # 系统首页
│   ├── FileUpload.tsx  # 文件上传页面
│   ├── FileDecompression.tsx # 解压缩处理页面
│   ├── ContentExtraction.tsx # 内容提取页面
│   ├── IntelligentAnalysis.tsx # 智能判别页面
│   ├── ResultsOutput.tsx # 成果表格输出页面
│   └── AIAssistant.tsx # AI助手页面
├── types/              # 类型定义
├── utils/              # 工具函数
└── services/           # 服务层
```

### 核心组件

#### FileDecompression 组件

- 解压缩处理主页面
- 支持批量文件解压缩
- 实时日志记录和状态监控
- 智能文件检测和问题提示

#### ResultsOutput 组件

- 成果表格输出主页面
- 模板管理和自定义创建
- 智能内容提取和表格生成
- 多格式导出功能

#### FilePreview 组件

- 文件解析结果预览对话框
- 支持多标签页展示不同类型的内容
- 响应式设计，适配不同屏幕尺寸

#### FileUpload 组件

- 文件上传主页面
- 集成了上传、处理、预览等完整功能
- 支持批量文件处理

### 数据流程

1. 文件上传 → 2. 格式验证 → 3. 解压缩处理 → 4. 内容解析 → 5. 智能判别 → 6. 成果表格输出

## 应用场景

### 地块违规建设报告审核

- 自动提取地块编号、违规类型、违规面积等关键信息
- 生成标准化的违规建设情况统计表
- 支持批量报告处理和数据汇总

### 土壤与水污染报告审核

- 识别检测点位、污染物名称、检测值等数据
- 自动计算超标倍数和风险等级
- 生成污染检测结果汇总表

### 通用报告信息提取

- 灵活的自定义模板配置
- 适应各种报告格式和内容结构
- 支持多种数据类型的提取和处理
