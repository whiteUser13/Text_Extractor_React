# 报告文件智能化审核应用系统

## 系统概述

报告文件智能化审核应用系统是一个基于人工智能技术的智能化报告审核平台，主要功能包括文件上传下载、格式转换、多模态内容解析、自定义规则提取和判别等。系统专门用于地块违规建设情况报告审核、土壤与水污染报告审核、地块报告中信息提取等业务场景。

## 核心功能

### 1. 系统首页（仪表板）
- 系统概览信息展示
- 处理报告数量统计
- 过程环节错误信息统计
- 具体处理进度展示
- 报告处理阶段状态监控
- 实时数据更新

### 2. 文件上传与管理
- 支持多种格式文件上传（PDF、Word、图片、压缩包等）
- 拖拽上传功能
- 文件信息监测记录（编号、文件名、格式、大小等）
- 批量文件处理
- 实时处理进度显示

### 3. 内容检索与提取
- 自定义提取规则配置
- 基于关键词的内容检索
- 特定章节定位
- 页码范围指定
- 结构化数据表生成
- 提取结果导出功能

### 4. 智能判别分析
- 自定义审核判别规则设计
- 多种判别类型支持：
  - 合规性判别
  - 等级分类判别
  - 含义解释判别
- AI驱动的智能分析
- 判别结果结构化输出

### 5. AI智能助手
- 专业的报告文件分析助手
- 支持文本对话和图片分析
- 基于已处理文件的智能问答
- 多模态内容理解
- 对话记录管理

## 技术架构

### 前端技术栈
- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **UI组件**: shadcn/ui + Tailwind CSS
- **路由**: React Router
- **状态管理**: React Context + Hooks
- **图标**: Lucide React

### 后端服务
- **OCR识别**: 百度通用文字识别（高精度版）
- **AI分析**: 文心一言多模态/文本生成大模型
- **图像理解**: 图像内容理解API
- **数据存储**: 本地数据服务（可扩展至Supabase）

### 核心处理流程
1. **转换**: 将报告文件转换为可解析的格式
2. **解析**: 把报告内容解析为包含原有结构、页码、逻辑关系的可检索内容
3. **检索**: 采用自定义检索规则进行内容检索
4. **提取**: 对检索内容进行整理提取为结构化数据
5. **判别**: 基于自定义判别规则输出结构化判别结果

## 快速开始

### 环境要求

```bash
Node.js >= 18
npm >= 8
```

### 安装依赖

```bash
npm install
```

### 配置环境变量

在项目根目录创建 `.env` 文件：

```env
# 应用配置
VITE_APP_ID=your_app_id

# API配置
VITE_API_BASE_URL=/api

# 系统配置
VITE_APP_NAME=报告文件智能化审核应用系统
VITE_APP_DESCRIPTION=智能化报告审核平台，支持多格式文件处理、OCR识别、内容分析和自定义规则判别
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## 使用说明

### 1. 文件上传
- 访问"文件上传"页面
- 拖拽文件到上传区域或点击选择文件
- 支持批量上传，系统会自动处理

### 2. 内容提取
- 在"内容提取"页面配置提取规则
- 设置关键词、目标章节等参数
- 查看提取结果并可导出为CSV

### 3. 智能判别
- 在"智能判别"页面配置判别规则
- 选择判别类型（合规性、分类、解释）
- 查看AI分析结果

### 4. AI助手
- 与AI助手进行对话
- 上传图片进行分析
- 基于已处理文件进行问答

## 开发指南

### 添加新页面
1. 在 `src/pages/` 目录创建新的页面组件
2. 在 `src/routes.tsx` 中添加路由配置
3. 在Header组件中添加导航链接

### 扩展数据服务
1. 在 `src/types/index.ts` 中定义新的数据类型
2. 在 `src/services/dataService.ts` 中添加相应的数据操作方法
3. 在页面组件中使用数据服务

### 集成新的AI服务
1. 在 `src/utils/api.ts` 中添加新的API调用方法
2. 在 `src/services/processingService.ts` 中集成处理逻辑
3. 更新相关的类型定义
